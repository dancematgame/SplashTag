SplashTag v1.0

To celebrate the spirit of community and teamwork embelished in WoW Forever, I've written an addon that allows the user to solo tag mobs as quickly and efficiently as possible.

How To Play : 
1. Copy SplashTag to your addons folder.
2. Make a blank macro called Splashtag.
3. Place it on a bar and keybind it to something that you can spam.
4. Open the config menu (Star icon or /st) and select the spell that you actually want to tag mobs with.
5. Go to a spawn spot, select the mob you want to tag, and spam that button!

If you need to tag a mob that isn't in the preset list, just type any name into the addon window, and press Enter to set it as the current target.

Considerations : 
Although this is a WoW Forever addon, the list of Preset Mobs was generated by scraping data from WoW Classic. I don't plan to update the list after Forever has launched, as I consider it feature-complete. Typing the first few letters of a Wow Forever mob's name into the addon window should still allow you to tag the mob quicker than most players, and will give a small edge over speedrunners who are manually editing their own macros.

Using this addon and then manually spamming a button does not constitute automation. However, using an external program to press the button for you may constitute automation.
